개인정보 처리방침

NumKB Mac 앱과 웹 숫자 키패드의 개인정보 및 사용 안내.

2026년 10월 12일 업데이트

01

적용 범위

Mac 앱, 휴대폰 웹 키패드와 이 웹사이트에 적용됩니다. 별도의 NumKB 계정은 필요하지 않습니다. App Store 구매는 Apple 계정을 사용합니다.

02

입력과 연결

키 명령은 로컬 네트워크로 휴대폰에서 Mac으로 전송됩니다. 개발자 서버에 업로드하거나 입력 기록을 저장하지 않습니다. 손쉬운 사용 권한으로 활성 Mac 앱에 요청한 키를 보냅니다. 웹 연결은 암호화되지 않은 HTTP이므로 신뢰할 수 있는 사설 네트워크를 사용하세요.

03

기기의 데이터

Mac은 재연결과 중복 입력 방지를 위해 페어링 기기 이름·식별자, 세션 인증 정보, 출처, 연결 시간, 입력 순서를 저장합니다. 언어와 포트 설정도 Mac에 저장됩니다. 브라우저 로컬 저장소에는 임의 기기 식별자, 탭 세션 저장소에는 페어링 정보가 저장됩니다. Mac 키체인에는 시계 변경으로 체험을 재시작하지 못하도록 최근 확인 시간을 저장합니다.

04

구매와 진단

Apple은 결제를 처리하고 검증된 거래 정보를 제공하여 7일 체험과 Pro 영구 이용을 확인합니다. 카드 정보는 받지 않습니다. 로컬 진단에 서비스·연결·권한 상태가 포함될 수 있습니다. 광고, 분석, 개발자에게 자동 전송되는 원격 측정 서비스는 없습니다.

05

이 사이트는 쿠키, 추적 스크립트, 온라인 양식을 추가하지 않습니다. GitHub Pages는 IP 주소와 요청 정보를 처리할 수 있습니다. 문의 이메일 주소와 제공한 내용은 답변과 조사에 사용하며 지원이나 법적 의무에 필요한 기간만 보관합니다. 양측 이메일 서비스가 메시지를 처리합니다.
